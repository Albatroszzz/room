# Инструкция по работе с Git

##  1. Создание репозитория
Чтобы создать пустой репозиторий, используем команду (перенос на следующую строку - два пробела + энтер):  
> **git init** - инициализация репозитория.

## 2. Добавление файла в отслеживание и коммит

> **git add filename** - добавить в отслеживание файл с именем *filename*  
> или **git add .** - добавить в отслеживание все измененные файлы.  
> **git commit -m "комментарий"** - создание коммита
